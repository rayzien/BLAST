# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.3.x   | :white_check_mark: |
| 1.2.x   | :white_check_mark: |
| < 1.2.0 | :x:                |

## Reporting a Vulnerability

Security is paramount to BLAST. If you discover a vulnerability or security issue:

1. **Do not create a public GitHub issue.**
2. Send an email to the maintainers or report via private GitHub Security Advisory.
3. Include details of the vulnerability, proof of concept, and impact assessment.
4. Maintainers will acknowledge receipt within 48 hours and work on a fix.
